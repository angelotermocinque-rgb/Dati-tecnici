Per modificare unità esterne (gas e quantità) usa direttamente il foglio Google Unita_Esterne.

Come usare il portale

1. Cerca l’unità esterna

Scrivi marca o modello nella casella di ricerca e seleziona l’unità dall’elenco. Appare subito la tipologia e la quantità di gas.

2. Aggiungi le unità interne (se previste)

Se l’unità esterna prevede combinazioni con interne, puoi aggiungerle una alla volta. Puoi scegliere solo le unità che appartengono alla stessa combinazione registrata: non è possibile mischiare interne di combinazioni diverse.

3. Leggi i dati tecnici

Con la sola esterna vedi gas e quantità. Con la combinazione completa vedi anche potenza, COP, EER, SCOP, SEER e gli altri dati.

4. Modalità notte

Usa lo switch in alto a destra per passare al tema scuro. La preferenza viene ricordata.

I dati vengono aggiornati automaticamente quando torni sulla pagina o riprendi a cercare. Non serve ricaricare il browser dopo modifiche al foglio Google.

Documentazione tecnica

Architettura

  • Frontend: singolo file index.html (HTML + Tailwind CDN + JS vanilla).
  • Backend dati: Google Apps Script esposto come Web App (API_URL).
  • Storage: Google Sheet con due fogli principali — Unita_Esterne e Combinazioni.

Foglio Unita_Esterne

Una riga = un’unità esterna. Campi usati dal portale:

  • Marca, Unità Esterna — chiave di ricerca e collegamento.
  • Tipologia gas, Quantitativo gas — mostrati sempre dopo la selezione dell’esterna.

Gas e quantità si modificano solo da questo foglio (non dal form Admin).

Foglio Combinazioni

Una riga = una combinazione valida e atomica.

  • Chiave: Marca + Unità Esterna (+ UI1…UI5 se presenti).
  • UI1–UI5 vuote = combinazione “solo esterna” (dati tecnici senza interne).
  • Dati tecnici: Potenza riscaldamento, COP, EER, SCOP, SEER, Denominazione, Inverter, Reversibile, Superficie utile.

Regola fondamentale: le unità interne di righe diverse non sono abbinabili. Il portale propone solo UI presenti nella stessa riga, filtrando in base a quelle già selezionate.

Logica di ricerca (frontend)

  1. Selezione esterna → se esistono combinazioni con almeno una UI valorizzata, si attiva lo step interne; altrimenti si cerca la riga “solo esterna” e si mostrano i dati tecnici completi.
  2. Con interne possibili ma nessuna ancora scelta → solo gas/quantità da Unita_Esterne.
  3. UI compatibili = quelle di righe che contengono già tutte le UI selezionate.
  4. Se non restano UI compatibili, il campo “Aggiungi interna” viene nascosto.
  5. Match finale: confronto multiset delle UI (ordine irrilevante, case-insensitive).

API Apps Script (azioni)

  • get — restituisce { esterne, combinazioni }.
  • saveCombinazione — inserisce (password richiesta); se esiste già risponde con conflict.
  • overwriteCombinazione — sovrascrive riga esistente (password + rowIndex).

Refresh dati

  • Caricamento iniziale con overlay a tutto schermo.
  • Ricarica silenziosa se i dati hanno più di 30 secondi: al focus sulla ricerca, a ogni digitazione (se stale), e al ritorno sulla scheda del browser (visibilitychange).
  • In Admin: pulsante “Aggiorna dati”.

Admin – form nuova combinazione

Permette di salvare una combinazione (anche senza interne). Le UI si aggiungono a mano (Invio). Conflitti: conferma di sovrascrittura. Password inviata a ogni write; validazione lato Apps Script.

Manutenzione / evoluzioni tipiche

  • Nuovi campi tecnici → aggiungere colonna nel foglio Combinazioni, campo in showFullResult e nel form Admin, e gestirli nello script Google.
  • Cambio URL sheet o deploy script → aggiornare API_URL / SHEET_URL in cima allo script.
  • Tema: classe dark su html, preferenza in localStorage chiave t5-theme.
